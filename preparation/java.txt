Stream (Conveyer Belt Example)
1. Pipeline: Source ➡️ Intermediate (Lazy) ➡️ Terminal (Eager).
2. Memory: Original data is never mutated; new collections are allocated at the end.
3. map vs flatMap: map is 1-to-1 transformation; flatMap is 1-to-many (flattens a stream of streams).
4. Primitives: Use IntStream or LongStream to avoid the heap overhead of number boxing.
Streams are more for maintainability and readability than speed or memory.

basically abstract classes can be used to keep instance state but same is not possible with interfaces as it's more of a stateless. Abstract class used by multiple class can have common instance variable who data can be shared across if needed

abstract class can have stateful variable (public string) which will be shared by all sub classes 
interfaces are stateless and can't share any variable (private static final so immutable)

default methods flow till leaf classes and called using class instance
static methods don't flow like default but available in sub classes using interface

so default are like regular method of class - called by instance 
but static is like static method on class level - called using interface

functional interface - requirement - SAM - Single Abstract method but it can have many default/static methods
